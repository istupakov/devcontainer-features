# Dev Container Features

A collection of Dev Container Features maintained by Ilya Stupakov.

## Available Features

- [Codex](src/codex/README.md) — share host Codex configuration and state,
  with optional VS Code extension installation (`installExtension: true`).

## Development and testing

The repository's Dev Container includes Docker and installs the Dev Containers
CLI. Alternatively, install Docker, Node.js, and the CLI on your host:

```sh
npm install -g @devcontainers/cli
```

Run tests through the wrapper so your real Codex directory is never mounted:

```sh
./test/run.sh --skip-scenarios --base-image debian:bookworm-slim
./test/run.sh --skip-scenarios --base-image ubuntu:24.04
./test/run.sh --skip-autogenerated --skip-duplicated
python3 test/extension_test.py
```

The test wrapper uses temporary synthetic state, verifies that container writes
reach the host, and removes the fixture afterward. Tests cover root, vscode,
and node users without accessing your real Codex directory.

## Publishing

Run the **Release dev container features & Generate Documentation** workflow on
`main` to publish to GHCR. It also opens a pull request if generated Feature
documentation changes. Enable GitHub Actions to create pull requests in the
repository settings, and make the published GHCR package public for public use.
Feature-specific notes live in `NOTES.md` and are included in generated docs.
